# 10회차 Codex 판 — 2차 손질 요청 (Claude 가 찍은 화면 기준)

1차 결과를 6개 페이지 × 라이트/다크 × 1440/390px 로 찍었습니다(첨부). 오류 · 가로 넘침은 0건, 덱 뽑기 → 카트리지 꽂기 → 개요 동작도 네 안 모두 정상입니다.
정렬(첫 화면과 절의 왼쪽 선 x=93) · 본문 15px · 메뉴 읽히는 글꼴 · 첫 화면의 '01 프로젝트 보기 / 02 이력서 읽기' 바로가기는 좋습니다. 아래만 고쳐 주세요.
범위 · 금지 사항은 1차 지시서와 같습니다(`-cx` 파일과 themes.js 의 `fc-*-cx` 항목만, 커밋 · 푸시 금지, Claude 판 열람 금지).

## 네 안 공통
1. **네 안이 한 틀로 수렴했습니다.** 첫 화면 아래(절 머리 · 카드 · 강점 · 게임 목록 · 더 보기)만 보면 바탕색 말고는 구분이 거의 안 됩니다 —
   같은 빨간 윗선 강점 카드 · 같은 평범한 절 제목. 사용자가 전에 지적한 "화풍이 첫 화면에만 머문다"와 같은 문제입니다.
   각 안의 화풍을 본문에도 **절제해서** 이어 주세요(다시 조잡해지지 않게 — 장식을 붙이는 게 아니라 절 머리 · 카드 테두리 · 버튼 · 구분선의 '그리는 방식'으로).
   - 도트: 4px 검은 선 · 크림 면 · 주황 사선 줄무늬 · 도트 글꼴 큰 제목 같은 어휘가 지금 본문에서 거의 사라졌습니다.
   - 크라프트: 종이 · 진홍 2색 평면 포스터 느낌은 남았지만 강점 카드가 다른 안과 같은 틀입니다.
   - 스테이지: 아래 '스테이지' 항목.
   - 랠리 프린트: 기울임꼴 굵은 제목 · 사선 띠가 첫 화면에만 남았습니다(절 제목은 곧은 고딕).
2. 첫 화면 안내 문구 '카트리지를 골라 꽂으면…'(`.fcs-caption`)이 도트 · 랠리에서 13px 입니다 — 15px 이상으로.

## 스테이지 (`pixel-fc-level-cx`) — 꼭 고칠 것
1. **밝아진 본문 바탕 위에서 절 제목이 안 보입니다.** `.hp-h` · `.section__title` 등 글자색이 `#fffdf3`(크림) + 옅은 그림자라
   홈 · 이력서 · 자기소개서 · 프로젝트 · 게임플레이 모든 절 제목이 바탕에 묻힙니다(라이트 1440px · 390px 모두. 다크에서는 보임).
2. 이력서 숫자 카드(`.stat`)의 이름표가 남색 막대 안에서 짙은 글자(rgb 80 82 96)라 안 보입니다.
3. 절 끝 '이력서 →' 등 빨간 버튼의 글자가 왼쪽 테두리에 붙어 잘려 보입니다(안쪽 여백 부족).

## 크라프트 (`pixel-fc-kraft-cx`)
1. 390px 에서 게임기 화면 속 '이력서' · '포트폴리오' 버튼이 화면 대부분을 차지하는 큰 빨간 덩어리가 됩니다.
2. 강점 카드에 큰 번호 '01' 과 태그 '01 / DOCUMENT' 가 겹쳐 번호가 두 번 나옵니다.

## 랠리 프린트 (`pixel-fc-rally-cx`)
1. 절 사이에 화면 끝에서 끝까지 그은 구분선과 절 제목 밑줄이 겹쳐 줄이 두 번 나옵니다.
