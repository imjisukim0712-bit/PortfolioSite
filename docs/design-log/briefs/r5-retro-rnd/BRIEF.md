## 3단계 — 시안 제작
- 출발점: `pixel-fc-classic` 을 복제(`sed 's/pixel-fc-classic/<새 id>/g'` 로 CSS·JS 둘 다)한 뒤 마음껏 바꾸세요. 새 id 는 `pixel-fc-<짧은 영문>`.
- `assets/js/themes.js` 의 pixel 테마 `variants` 에 항목 추가(ko/en 이름·설명 · swatch · `scripts: ['js/themes/<id>.js', 'js/themes/fc-stage.js']`),
  `assets/js/themes/fc-stage.js` 의 `SKINS` 에 id 추가. 이 둘 말고 공용 파일은 건드리지 마세요.
- **고정(반드시 유지)**: 첫 화면 구도 = 왼쪽 큰 제목 · 오른쪽에 살짝 3D 로 기울어진 패미컴 휴대용 게임기 · 그 바로 밑 같은 기울기의 카트리지 진열판
  (fc-stage.js 배치 + 각자 CSS 의 `.fcs-rig` transform). 게임기 실루엣(양옆 손잡이·가운데 화면·버튼 자리), 카트리지 꽂기 → 화면 개요 → 자세히 보기 동작,
  슬롯·z-index·좌표계(CLAUDE.md 패미컴 절). 빨강 패미컴 중심 색(톤 조정 OK).
- 품질 기준(사용자가 지금까지 거듭 지적한 것): 게임기 그림이 **깨지거나 조잡하면 실패** — 상자 조각을 여러 개 쌓아 그리면 기울였을 때 모서리가 틀어집니다.
  몸통은 SVG 한 장으로 그리는 방식(`assets/js/themes/fc-body.js` 참고 — 읽기만, 수정 금지; 필요하면 같은 방식을 당신 JS 안에 따로)을 권합니다.
  외곽선이 모서리에서 끊기거나 픽셀 한 칸이 튀어나오면 안 됩니다. 평면적이어서 바탕에 묻히면 안 됩니다(두께·그늘·그림자로 입체감).
  화풍은 첫 화면만이 아니라 메뉴·절·카드·표·버튼·푸터·하위 페이지(이력서·자기소개서·프로젝트·게임플레이·프로젝트 상세)까지 사이트 전체에.
- 규칙: 닌텐도·마리오 등 **로고·상표·캐릭터 복제 금지**(월계관·금박·엠블럼·숫자 타이포 같은 일반 형식은 OK, 소품은 사이트 고스트·하트·별·코인 등 직접 만든 것).
  사진(프로필)에 filter·오버레이·혼합모드·픽셀화 금지. `.gcard` 안쪽 cqw 고정 칸·카드 안 미디어 쿼리 금지. 도구 로고 판은 흰색.
  새 글자는 ko/en 둘 다. 라이트·다크 둘 다. 1440×900 · 1280×720 · 390×844 · 320px 가로 넘침 없음. `prefers-reduced-motion` 존중.
  웹 글꼴이 필요하면 themes.js 시안 항목의 `fonts: [G + '...']`(구글 폰트)로.
- 갤러리 미리보기 `assets/img/themes/<id>.jpg` (1280×800 홈 첫 화면 → 800×500).
