## 당신의 안
`pixel-fc-iso` · 새 참고 그림 ⑥(그림 첨부 없음): 흰 바탕 위 **아이소메트릭 만화풍 레트로 게임기 일러스트** — 굵은 남색/청회 외곽선(일정 두께·둥근 끝),
평면 색 + 그림자 한 단계, 세이지 초록(#8fb58a) 윗판, 살구·탄 베이지(#e8b98a/#f2d4a8) 본체, 청회 남색(#4a5a7a) 옆면, 벽돌 빨강(#b5413a) 받침·버튼, 겨자(#e9c46a), 크림(#f6efe2).
카트리지 라벨에 노랑·초록·빨강 둥근 막대. 큰 둥근 모서리와 아래쪽 두꺼운 짙은 받침면. **콘셉트: '장난감 같은 두툼한 만화 오브젝트'.**
- 모든 상자·카드·버튼: 남색 3px 선 + **아래쪽 두꺼운 받침 면(8~12px, 더 짙은 색, 둥근 모서리)** 으로 물건처럼 두툼하게. 눌린 버튼은 받침이 줄어듦.
- 게임기: 본체 벽돌 빨강, 위 베젤 세이지 초록 판, 아래 받침 청회 남색 두께, 버튼은 빨강·초록·청회 둥근 단추(위쪽 하이라이트 한 줄).
- 제목: Jua/Do Hyeon 같은 둥근 굵은 한글 + 남색 선. 카트리지 라벨에 노랑·초록·빨강 둥근 막대 3줄.
- 절 배치: 각 절을 두툼한 **쟁반(트레이)** 위에 올린 듯(받침면 있는 큰 둥근 판), 강점 3장은 블록 장난감처럼 서로 다른 높이, 숫자 4칸은 둥근 단추 모양.
- 바탕: 크림 + 아주 옅은 아이소 마름모 격자.
