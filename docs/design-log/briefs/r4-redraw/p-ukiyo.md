## 당신의 안
`pixel-fc-ukiyo` · 참고 그림 ⑤ 일본 레트로 판화(첨부 마지막). **콘셉트: '목판 인쇄물'.**
- 바탕: 종이결(SVG feTurbulence 노이즈를 data URI 배경으로, 아주 옅게) 크림.
- 모든 색 면은 **판 어긋남**: 색 면과 갈색 선이 2~3px 어긋나 찍힌 듯(테두리 선은 제자리, 색 채움은 살짝 비켜 — box-shadow/::before 로).
- 게임기: 산호 빨강 평면 + 굵은 갈색 선화, 손잡이에 **청해파(물결 비늘) 무늬** 판, 화면 위 베젤에 구름 소용돌이 띠.
- 제목: 세리프 한글(Gowun Batang Bold 또는 Noto Serif KR 900 / Hahmlet) 대형 + 옆에 **세로쓰기 라벨**(writing-mode: vertical-rl, '포트폴리오' 등) + 빨간 **낙관 도장**(정사각 산호 도장에 흰 글자 '김').
- 절 배치: 절 제목 앞에 세로 띠 번호(壱弐参 대신 01 02 03), 절 사이 구분은 청해파 띠/구름 띠, 강점 3장은 세로로 긴 족자(위아래 막대) 모양, 숫자 4칸은 도장 찍힌 표.
- 메뉴·푸터: 갈색 선 테두리의 인쇄물 머리띠, 푸터는 물결 띠 위.
