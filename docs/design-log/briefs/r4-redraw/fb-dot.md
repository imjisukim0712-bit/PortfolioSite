# 2차 — 실제 화면 확인 결과 (첨부 1 = 지금 당신 안: 첫 화면 · 그 아래 · 이력서 · 다크 · 모바일, 첨부 2 = 제목 확대(오른쪽 위가 당신 안))
오류·가로 넘침 없음, 꽂기 정상. 아래 절의 큰 번호 열·부품 상자는 좋습니다. 고칠 점:
1. **큰 제목이 너무 가늘어** 위계가 약합니다(Galmuri 400). `Galmuri11` 은 700 굵기가 있으니 font-weight:700 + 더 큰 크기 + 검은 4px 도트 그림자(오른쪽·아래 한 칸)로 단단하게.
   본문·작은 라벨도 가는 도트 글자가 많아 읽기 힘듭니다 — 본문은 Pretendard 유지, 도트 글꼴은 제목·번호·라벨에만.
2. **흑백으로 보면 첫 화면이 아직 정돈 안과 비슷**합니다. 게임기와 진열판에 '아이소 두께 면'을 확실히 보이게: 오른쪽·아래로 12~16px 의 회색 두께 면(비스듬한 평행사변형, 4px 계단 경계)과
   그 바깥 검은 4px 외곽선. 손잡이 위쪽 면은 밝은 크림 한 줄(윗면 하이라이트). 진열판도 같은 두께.
3. 다크 모드 바탕이 순검정이라 거칩니다 — 아주 짙은 남회(#14161c 근처) + 옅은 아이소 점 격자.
나머지는 유지. 끝나면 2~3줄.
