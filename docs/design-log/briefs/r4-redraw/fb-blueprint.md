# 2차 — 실제 화면 확인 결과 (첨부 1 = 지금 당신 안: 첫 화면 · 그 아래 · 이력서 · 다크 · 모바일, 첨부 2 = 제목 확대(왼쪽 아래가 당신 안))
오류·가로 넘침 없음, 꽂기 정상. 모눈·치수선·문서 번호 줄·2단 설명서 배치 방향은 좋습니다. 고칠 점:
1. **큰 제목이 가는 고정폭(GalmuriMono)이라 힘이 없고 흐립니다.** 제목은 Pretendard 800~900(짙은 남색, 자간 살짝 좁게)으로 단단하게 하고,
   고정폭 글꼴은 문서 번호·치수·라벨·절 번호 같은 '주석' 층에만. 강조어 밑의 빨강 이중 밑줄은 유지.
2. **전체가 너무 옅습니다**(베이지 위 연한 선 · 작은 연한 글자). 본문·카드 글자는 대비를 올리고(AA), 카드 테두리는 남색 1.5~2px 로 또렷하게,
   모눈은 지금보다 조금 옅게(내용과 경쟁하지 않게). 아래 절 카드들이 바탕에 녹아 구분이 안 됩니다 — 카드 면을 바탕보다 밝은 종이색으로.
3. 첫 화면 치수선·지시선의 라벨 글자가 너무 작아 안 보입니다(최소 11px). 
나머지는 유지. 끝나면 2~3줄.
