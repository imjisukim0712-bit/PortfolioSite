## 당신의 안
`pixel-fc-icon` · 참고 그림 ① 레트로 게임 아이콘 도트(첨부 마지막). **콘셉트: '앱 아이콘 타일 런처'.**
- 모든 것이 **계단식 도트 모서리(8px 두 단 계단 clip-path)** 의 두꺼운 타일: 남색 6px 외곽선 안에 청회색 액자 띠가 한 겹 더 도는 **이중 액자**(참고 그림의 테두리 그대로).
- 게임기: 계단 모서리 + 본체 아래쪽 **4px 체크 디더 명암 띠**(크림→살짝 어두운 크림), 손잡이는 빨강→주황 **가로 띠 3단**(그림의 노을 띠를 게임기 손잡이 안으로).
- 제목: Galmuri11 Bold 대형 + 남색 4px 도트 그림자(오른쪽 아래 한 칸 계단).
- 절 배치: 보유 기술은 큰 정사각 아이콘 타일 격자(앱 서랍), 강점 3장은 정사각 타일 + 큰 도트 숫자, 대회 활동은 타일 목록. 절 제목은 작은 정사각 아이콘 배지 + 도트 글자.
- 바탕: 크림 + 아주 옅은 8px 도트 격자. 상단 메뉴는 남색 타일 막대에 메뉴가 작은 타일 버튼들.
