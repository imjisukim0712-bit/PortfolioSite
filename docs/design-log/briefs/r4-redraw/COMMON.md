# 4차 작업 지시 — 색만 바꾼 안은 실패. '그리는 방식'부터 다르게.

당신은 게임 기획자 김지수의 포트폴리오(빌드 도구 없는 정적 사이트) 저장소의 독립된 git worktree 안에 있습니다. CLAUDE.md 를 먼저 읽으세요.
당신 몫은 시안 하나 — `assets/css/themes/<시안 id>.css` 와 `assets/js/themes/<시안 id>.js` 두 파일입니다(지금 파일 = 3차 결과).

## 사용자 반응 (그대로)
"근데 대부분 그냥 색깔만 따오고 크게 바뀐 게 없네. 다시 뽑아봐."

실제로 열 안이 모두 '정돈(pixel-fc-classic)' 안의 골격 — 같은 게임기 그림 방식, 같은 카트리지, 같은 절 배치, 같은 카드 모양,
같은 글꼴(Pretendard 굵은 고딕), 같은 버튼·태그 — 위에 색만 갈아 끼운 상태입니다. 첨부 1 = 지금 이 안, 첨부 2 = 기준인 '정돈' 안.

## 합격 기준 — '흑백 시험'
화면을 **흑백으로 바꿔도** 정돈 안과도, 다른 안과도 한눈에 다르게 보여야 합니다. 그러려면 색이 아니라 아래를 바꿔야 합니다.
**아래 항목 중 최소 7개를 정돈 안과 확실히 다르게** 만드세요(끝나면 항목별로 무엇을 했는지 보고):
1. **글꼴과 제목 처리** — 큰 제목의 서체·굵기·자간·줄 처리(외곽선 글자, 그림자 글자, 도트 글자, 세리프, 기하 둥근 글자 등).
2. **게임기를 그리는 기법** — 지금은 '평면 칠 + 검은 굵은 테두리 + 딱딱한 그림자'. 대신: 선만으로(채움 없음), 아이소 두께 옆면, 계단식 도트 모서리(clip-path 4px 계단),
   판화 어긋남, 종이 질감, 광택 하이라이트, 제도 치수선 등 **참고 그림의 렌더링 방식**으로. (실루엣=손잡이·화면·베젤·둥근 모서리·버튼 자리는 유지)
3. **카트리지·덱·진열판을 그리는 기법** — 같은 원리로. (cqw 고정 칸 구조는 유지, 겉 그림 방식은 바꿔도 됨)
4. **절 배치** — 첫 화면 아래 절들(숫자 4칸 · 대회 활동 · 보유 기술 · 강점 3장 · 게임플레이)의 **레이아웃 자체**: 열 수, 정렬, 큰 번호, 좌측 여백 열,
   카드 묶음 방식, 절 사이 구분 방식. CSS grid/flex 재배치는 자유(내용·DOM 순서·링크는 그대로, 숨기지 말 것).
5. **절 제목 체계** — 리본, 번호, 세로 띠, 블록 아이콘, 괘선 등 그 화풍만의 머리 장식.
6. **카드·상자 모양** — 모서리 규칙(계단/둥근/직각/찢긴 종이), 테두리 방식(이중선/평행선/두께면/점선), 그림자 방식.
7. **버튼·태그·탭** — 모양과 눌림 표현.
8. **상단 메뉴와 푸터** — 그 화풍의 부품으로(예: HUD 줄, 설명서 머리말, 포스터 띠).
9. **바탕 처리** — 질감(종이결·망점·도트 격자·제도 모눈), 무늬, 배경 장식(낮은 대비로, 글을 방해하지 않게).
10. **하위 페이지**(이력서 · 자기소개서 · 프로젝트 목록 · 게임플레이 · 프로젝트 상세) — 같은 규칙이 실제로 보여야 함.

## 고정 (바꾸지 말 것)
- **첫 화면 구도**: 왼쪽 큰 제목 · 오른쪽 살짝 3D 로 기울어진 게임기 · 그 바로 밑 같은 기울기의 카트리지 진열판 (`fc-stage.js` 배치 + 당신 CSS 의 `.fcs-rig` 각도 그대로).
- **실루엣**: 패미컴 휴대용 게임기 모양, 카트리지(단자·귀·라벨), 덱.
- **색 콘셉트**: 빨강 패미컴 중심(게임기·핵심 강조는 빨강 계열 — 톤 조정은 OK).
- **동작**: 카트리지 꽂기 → 화면 개요 → 자세히 보기, 손잡이 버튼, 슬롯·z-index·좌표계 (CLAUDE.md 패미컴 절). JS 의 동작 부분은 건드리지 말고 장식만 더하세요.
- `.fcs-rig` 계단 현상 방지(will-change · backface-visibility · 투명 outline).

  다른 웹 글꼴(구글 폰트의 한글 서체: Black Han Sans · Do Hyeon · Jua · Gowun Dodum · Gowun Batang · Noto Serif KR · Hahmlet · Nanum Gothic Coding ·
  IBM Plex Sans KR · Orbit · Dongle · Gaegu 등, 영문 서체 아무거나)가 필요하면 CSS 파일 **맨 첫 줄**에 `/* FONTS: <구글 폰트 css2 URL> */` 한 줄로 적으세요 —
  제가 themes.js 에 등록합니다. 한글이 없는 서체는 영문·숫자 전용으로만.
- 상표·기존 캐릭터 금지(닌텐도·슈퍼 패미컴 로고, 마리오·굼바 등). 소품이 필요하면 사이트 고스트·하트·별·코인 등 직접 만든 것.
- 사진(프로필) filter·오버레이·혼합모드·픽셀화 금지(테두리·액자만). `.gcard` 안쪽 cqw 칸·카드 안 미디어 쿼리 금지. 도구 로고 판은 흰색.

- 실사용 품질: 본문 대비 AA(4.5:1)↑, 강한 색 바탕 위 작은 글자 금지, 위계 분명. 장식은 대담하되 글을 가리지 않게.

- 브라우저는 못 띄우니 선택자는 실제 마크업(render.js · HTML)을 읽고 맞추세요. git commit / push 금지.
- 끝나면 제가 실제 화면을 찍어 2차 피드백을 드립니다.
