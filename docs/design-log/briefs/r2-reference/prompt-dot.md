# 작업 지시 — 참고 그림 한 장의 '색과 화풍'을 패미컴 시안에 입히기

당신은 게임 기획자 김지수의 포트폴리오(빌드 도구 없는 정적 사이트) 저장소의 독립된 git worktree 안에 있습니다.
당신의 시안 파일(CSS·JS)은 '정돈' 안(`pixel-fc-classic`)을 그대로 복제한 것입니다 — 첨부 1 = 지금 모습(첫 화면), 첨부 2 = 홈 전체.
마지막 첨부 = **사용자가 올린 참고 그림**(당신 몫은 한 장).

## 사용자의 말 (그대로)
"구도는 내가 아까 좋다고 한 구도 — 살짝 3D로 돌아간 형태 — 고정으로 하고, 내가 올린 그림들 하나하나 확인해보고 각각 나름 녹여내서
화풍으로 적용시켜봐. 각각의 시안으로 만들어. **색이랑 화풍을 위주로 참고해. 패미컴 실루엣 자체를 바꾸란 게 아님.**"
이전 시도는 "구도도 달라지고 퀄리티도 너무 떨어졌다"는 평을 받았습니다. 퀄리티가 원본 '정돈' 안보다 낮아지면 실패입니다.

## 고정 (절대 바꾸지 말 것)
- **구도**: 왼쪽 큰 제목 · 오른쪽에 살짝 3D 로 기울어진 게임기 · 그 바로 밑 같은 기울기의 카트리지 진열판. 자리 옮기기는 공용 `assets/js/themes/fc-stage.js`, 기울기는 당신 CSS 의 `.fcs-rig` transform 입니다 — **각도·배치·크기 비율 그대로.**
- **실루엣**: 패미컴 휴대용 게임기 모양(양옆 손잡이 · 가운데 화면 · 위아래 베젤 · 둥근 모서리 · 손잡이 버튼 위치), 카트리지 모양(단자·귀·라벨), 덱. 형태를 다른 기기로 바꾸지 마세요.
- **동작**: 카트리지 꽂기 → 화면에 개요 → 자세히 보기, 손잡이 버튼, 슬롯·층(z-index)·좌표계 (CLAUDE.md 의 패미컴 절).
- 기울인 판의 계단 현상 방지 규칙(`.fcs-rig` 의 will-change · backface-visibility · 투명 outline)은 지우지 마세요.

## 바꿀 것 = 참고 그림의 '색'과 '화풍'
참고 그림을 자세히 보고 다음을 뽑아 사이트 전체(게임기 · 카트리지 · 덱 · 진열판 · 배경 · 상단 메뉴 · 버튼 · 절 카드 · 하위 페이지 · 푸터 · 라이트/다크)에 입히세요:
- **팔레트**(배경색, 본체색, 포인트색, 외곽선 색) — 참고 그림의 색을 그대로 뽑아 토큰으로.
- **선**(외곽선 두께·색, 선 끝 모양), **명암 방식**(평면/두 단계/도트 계단/광택 사선 등), **질감**(도트·종이결·망점 등), **장식 모티프**(참고 그림에 있는 것만), **글꼴 느낌**.
- 게임기 실루엣 위에 참고 그림의 디테일 언어를 입히는 방식으로(예: 띠·광택 사선·도트 명암·지시선 라벨). 형태는 그대로, 칠과 선이 바뀝니다.

## 규칙
- 당신의 CSS·JS 두 파일만 수정. 수정 금지: `style.css` `render.js` `main.js` `content.js` `overrides.js` `skin.js` `pixel.css` `pixel-famicom.css` `famicom.js` `fc-stage.js`, 다른 시안, HTML, `themes.js`.
  (장식 요소가 필요하면 당신 JS 에서 시안 id 일 때만 DOM 을 더하세요. 그림은 CSS·인라인 SVG 로 — 외부 이미지 금지.)
- 사진(프로필)에 filter·오버레이·혼합모드·픽셀화 금지(테두리·액자만). 카드(`.gcard`) 안쪽 cqw 칸 유지·카드 안 미디어 쿼리 금지. 도구 로고 판은 흰색.
- 도트 화풍이라도 **기울인 판 위에서 깨져 보이지 않게**: 아주 작은 1px 계단을 남발하지 말고, 도트 느낌은 큼직한(4px 이상) 격자·평면 색 단계로 표현하세요.
- 새 글자 ko/en. 라이트·다크 둘 다(다크도 같은 화풍). 1440×900 · 1280×720 · 390×844 · 320px 가로 넘침 없음. `prefers-reduced-motion` 존중.
- git commit / push 금지.

## 당신의 참고 그림
시안 id `pixel-fc-dot` · 파일 `assets/css/themes/pixel-fc-dot.css`, `assets/js/themes/pixel-fc-dot.js` · **참고 그림 ②: 흰 바탕의 깔끔한 패미컴 도트 그림** — 흰 바탕, 크림(#ffdca8 근처)·진홍(#b0122e 근처)·주황(#f5a000 근처)·회색·검정 외곽선만. 명암은 회색 한 단계와 흰 하이라이트 줄, 진홍 띠에 주황 사선 줄무늬. 게임기를 크림 본체 + 진홍 손잡이 + 검은 외곽선으로, 카트리지·덱도 같은 팔레트.
