# 2차 — 실제 화면 확인 결과 (첨부 1 = 지금 첫 화면, 첨부 2 = 참고 그림)
전체적으로 좋습니다(오류·넘침 없음, 꽂기 동작 정상). 고칠 점은 하나:
참고 그림의 가장 눈에 띄는 요소인 **게임기 뒤 액자 속 풍경(후지산 실루엣 + 눈 덮인 꼭대기, 소용돌이 구름 띠, 도트로 찍은 해, 아래쪽 청록 언덕)** 이
지금은 거의 보이지 않습니다(액자 윗변과 작은 구름만 보임). 게임기 오른쪽 위로 액자가 더 드러나고, 그 안에 산(청록 + 흰 눈) · 구름 · 도트 해(산호·주황 체크)가
분명히 보이게 인라인 SVG 로 그려 주세요 — 참고 그림처럼 굵은 갈색 선화 + 평면 색. 왼쪽 제목과는 겹치지 않게, 기울인 판(.fcs-rig) 뒤에(판보다 아래 층) 두고,
모바일(≤700px)에서는 작게 또는 숨김. 다크 모드에서는 밤 버전(남색 하늘 · 크림 달)으로. 나머지는 건드리지 마세요. 끝나면 2~3줄.
