## 당신의 안
시안 id `pixel-fc-iso` · **새 참고 그림 ⑥** (이미지는 첨부 못 함 — 설명으로): 흰 바탕 위 **아이소메트릭 만화풍 레트로 게임기 일러스트**.
굵은 남색/짙은 청회 외곽선(일정 두께, 둥근 끝), 평면 색 + 그림자 한 단계. 팔레트: 세이지 초록(#8fb58a, 윗판), 살구·탄 베이지(#e8b98a / #f2d4a8, 본체),
청회 남색(#4a5a7a, 옆면·카트리지 뒷판), 벽돌 빨강(#b5413a, 받침·버튼), 겨자 노랑(#e9c46a, 슬롯 표시), 크림(#f6efe2). 카트리지 라벨에 노랑·초록·빨강 둥근 막대.
모서리는 크고 둥글며 두께감이 아이소 옆면(아래·오른쪽 짙은 면)으로 표현됨. 귀엽고 정돈된 일러스트 아이콘 느낌.
적용: 게임기는 빨강 본체 유지(벽돌 빨강 톤) + 세이지 초록·베이지 면 나눔 + 남색 굵은 선, 카드·버튼·절 상자는 '아이소 두께 면 + 굵은 선' 규칙, 사이트 전체로.
