## 당신의 안
시안 id `pixel-fc-level` · **새 참고 그림 ⑩** (설명으로): **8비트 횡스크롤 게임 1-1 스테이지 장면.** 하늘색(#5c94fc) 하늘, 주황 '?' 블록(#fca044 면 · #c84c0c 그림자 · 검은 테두리 · 리벳 점),
갈색 벽돌 줄(#c84c0c / 짙은 줄눈), 둥근 초록 언덕(#00a800 + 짙은 초록 점), 흰 구름, 땅 블록 줄(바닥). 전부 큼직한 도트.
적용: 사이트를 '스테이지'로 — 하늘색 바탕 면, 첫 화면 아래와 푸터에 땅 블록 띠, 절 제목 옆 '?' 블록 아이콘, 카드·절 상자는 블록/벽돌 테두리 규칙,
숫자 4칸은 '?' 블록에서 튀어나온 코인 점수처럼. 게임기는 빨강 패미컴 그대로(하늘 위에 뜬 무대 소품). 본문은 흰/크림 면 위에서 읽히게.
캐릭터(마리오·굼바 등) 복제 금지 — 생물이 필요하면 사이트 고스트.
