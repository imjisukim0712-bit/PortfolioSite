## 당신의 안
시안 id `pixel-fc-dot` · **참고 그림 ②(재해석)** — 흰 바탕의 깔끔한 아이소 패미컴 도트(첨부 마지막 장). 첨부 1 = 지금 이 안.
지금 문제: '정돈' 안의 색만 바꾼 느낌이라 개성이 약하고, 흰 바탕에 검은 그림자만 있어 밋밋함. 아래 절은 정돈 안 그대로.
재해석 방향: **'아이소 도트 부품' 시스템.** 크림·진홍·주황·회색·검정 다섯 색만. 회색 한 단계 옆면(아이소 두께)을 카드·버튼·절 상자에 일관되게
(오른쪽·아래로 4~8px 회색 면 = 입체 두께), 진홍 띠 안의 **주황 사선 줄무늬**를 사이트의 서명 무늬로(절 제목 밑줄, 진행 바, 활성 탭, 카드 띠).
4px 도트 격자 모서리(계단 2단 정도)로 버튼·태그 모서리를 깎아 도트 감각. 흰 바탕은 유지하되 절마다 크림 면으로 리듬.
