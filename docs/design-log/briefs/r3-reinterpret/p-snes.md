## 당신의 안
시안 id `pixel-fc-snes` · **새 참고 그림 ⑧** (설명으로): **호박색(#f2a51f) 바탕 위 정교한 고해상 도트 그림** — 회백색(#ddd8d0) 본체와 짙은 회색(#9a958e/#6f6a64) 판,
2~3단 부드러운 도트 명암, 물체 둘레 1도트 흰 테두리(스티커처럼 떠 보임), 컨트롤러의 파랑·빨강·초록·노랑 네 버튼, 옆에 카트리지가 층층이 쌓인 기둥.
적용: 빨강 중심 조건 때문에 게임기는 **회백 본체 + 빨강 손잡이/포인트**(그림의 빨간 전원 표시·빨강 버튼을 키운 해석), 도트 명암은 4px 격자 이상,
물체 둘레 흰 테두리 + 호박색 바탕 면을 사이트 서명으로(단, 본문 읽는 면은 회백/크림). 카드 진열판은 '쌓인 카트리지 선반' 느낌, 버튼은 네 색 중 빨강 주색.
