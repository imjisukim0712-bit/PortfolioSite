# 3차 작업 지시 — '그대로 쓸 수 있는' 완성 시안으로

당신은 게임 기획자 김지수의 포트폴리오(빌드 도구 없는 정적 사이트) 저장소의 독립된 git worktree 안에 있습니다. CLAUDE.md 를 먼저 읽으세요.
당신 몫은 시안 하나 — 파일은 `assets/css/themes/<시안 id>.css` 와 `assets/js/themes/<시안 id>.js` 두 개뿐입니다.

## 사용자 반응 (그대로)
1차 다섯 안에 대해: "5개 다 독특하긴 한데 그대로 쓰긴 어려울 것 같아. 5개 다 그 상태에서 재해석해서 좀 더 바꿔봐."
그리고 새 참고 그림 다섯 장을 더 주며: "얘네로도 각각 시안 뽑아."

## 우리가 진단한 '그대로 쓰기 어려운' 이유 (모든 안 공통으로 고칠 것)
1. **화풍이 첫 화면 게임기에만 머묾.** 그 아래(숫자 4칸 · 대회 활동 · 보유 기술 · 강점 카드 · 게임플레이 · 푸터)와 하위 페이지
   (이력서 · 자기소개서 · 프로젝트 · 게임플레이 · 프로젝트 상세)는 다섯 안이 거의 똑같은 '정돈' 안 그대로입니다.
   → 화풍을 **사이트 전체의 디자인 시스템**으로 만드세요: 토큰(바탕·면·글자·선·강조), 선 두께와 모서리 규칙, 그림자/명암 방식,
   절 제목 장식, 카드·표·태그·버튼·탭·입력칸·구분선·푸터, 상단 메뉴, 라이트/다크. 어느 페이지를 열어도 같은 안이라는 게 보여야 합니다.
2. **참고 그림을 너무 문자 그대로 옮김.** 그림 속 소품을 스티커처럼 붙이는 대신, 그 그림의 **조형 언어**(색 비율, 선, 면 나누기, 질감,
   반복 무늬, 글꼴 느낌)를 뽑아 절제해서 체계적으로 쓰세요. 장식은 적게, 대신 일관되게. 정보(글·사진·카드)가 늘 주인공.
3. **실사용 품질.** 실제 포트폴리오로 바로 내보낼 수 있는 완성도: 본문 글자 대비 WCAG AA(4.5:1) 이상, 작은 글자를 강한 색 바탕에 얹지 않기,
   위계(제목 > 부제 > 본문 > 보조) 분명, 여백 리듬 일정, 모바일에서 답답하지 않게. 장식이 글을 가리거나 시선을 빼앗으면 실패.

## 고정 (절대 바꾸지 말 것)
- **구도**: 왼쪽 큰 제목 · 오른쪽에 살짝 3D 로 기울어진 게임기 · 그 바로 밑 같은 기울기의 카트리지 진열판
  (자리 옮기기 = 공용 `fc-stage.js`, 기울기 = 당신 CSS 의 `.fcs-rig` transform — 각도·배치·크기 비율 그대로).
- **실루엣**: 패미컴 휴대용 게임기(양옆 손잡이 · 가운데 화면 · 위아래 베젤 · 둥근 모서리 · 손잡이 버튼 위치), 카트리지(단자·귀·라벨), 덱.
- **색 콘셉트**: 사용자가 못박은 조건 — **빨강 패미컴이 중심**(게임기·핵심 강조색은 빨강 계열, 참고 그림 톤에 맞춰 빨강을 조정하는 건 OK).
- **동작**: 카트리지 꽂기 → 화면에 개요 → 자세히 보기, 손잡이 버튼, 슬롯·층(z-index)·좌표계 (CLAUDE.md 패미컴 절).
- `.fcs-rig` 의 계단 현상 방지(will-change · backface-visibility · 투명 outline) 유지.

## 규칙
- 당신의 CSS·JS 두 파일만 수정. 수정 금지: `style.css` `render.js` `main.js` `content.js` `overrides.js` `skin.js` `pixel.css`
  `pixel-famicom.css` `famicom.js` `fc-stage.js`, 다른 시안, HTML, `themes.js`. (장식 DOM 이 필요하면 당신 JS 에서 시안 id 일 때만.
  그림은 CSS·인라인 SVG — 외부 이미지 금지. 글꼴은 이미 읽히는 것 + 시스템 글꼴 안에서.)
- 상표·캐릭터 복제 금지: 닌텐도/슈퍼 패미컴 로고, 마리오·굼바 등 기존 게임 캐릭터를 그리지 마세요. 필요하면 사이트의 고스트나
  하트·별·코인 같은 **직접 만든 일반 도트 소품**으로.
- 사진(프로필)에 filter·오버레이·혼합모드·픽셀화 금지(테두리·액자만). 카드(`.gcard`) 안쪽 cqw 칸 유지·카드 안 미디어 쿼리 금지.
  도구 로고 판은 흰색(`.tool__ic` · `.hp-skill__ic--logo`).
- 도트 화풍이라도 기울인 판 위에서 깨지지 않게: 1px 계단 남발 금지, 도트는 4px 이상 격자·평면 색 단계로.
- 새 글자는 ko/en 둘 다. 라이트·다크 둘 다(다크도 같은 화풍). 1440×900 · 1280×720 · 390×844 · 320px 가로 넘침 없음. `prefers-reduced-motion` 존중.
- 브라우저는 못 띄우니 CSS 선택자는 실제 마크업(render.js · 각 HTML)을 읽고 맞추세요. git commit / push 금지.
