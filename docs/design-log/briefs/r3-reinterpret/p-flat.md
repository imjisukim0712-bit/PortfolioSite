## 당신의 안
시안 id `pixel-fc-flat` · **참고 그림 ④(재해석)** — 하늘색 바탕 둥근 플랫 일러스트(첨부 마지막 장). 첨부 1 = 지금 이 안.
지금 문제: 하늘색 바탕과 베이지 상단 메뉴가 따로 놀고, 카드·진열판이 물 빠진 색이며, 갈색 선·빨강 광택 띠 같은 그림의 핵심 언어가 게임기 밖으로 안 나옴. 아래 절은 정돈 안 그대로.
재해석 방향: **'둥근 플랫 일러스트' 시스템.** 모든 상자·버튼·카드·사진 액자에 갈색(#6b3a2a 근처) 3px 외곽선 + 큰 둥근 모서리 + 같은 색 옅은 그림자 한 겹,
빨강 띠에 **흰 반투명 사선 광택 두 줄**을 서명으로(상단 메뉴 활성, 주 버튼, 절 제목 리본, 카드 라벨 띠). 하늘색은 바탕 면, 크림은 내용 면으로 역할을 나누고
상단 메뉴도 같은 체계로. 다크는 깊은 남청 하늘 + 같은 갈색 선(밝게 조정).
