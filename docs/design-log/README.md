# 디자인 회의록 — 패미컴 시안 작업 (2026-10-26 ~ 10-28)

김지수(사용자)와 Claude(누렁이)가 포트폴리오 첫 화면 · 사이트 디자인을 두고 나눈 이야기와 결정, 그에 따른 시안을 시간 순으로 정리했습니다.
시안은 모두 저장소에 있고 갤러리(`themes.html`)나 `index.html?skin=<시안 id>` 로 열어 볼 수 있습니다.
Codex(보조 에이전트)에게 준 지시서는 [`briefs/`](briefs/), 회차별 비교 화면은 [`images/`](images/) 에 있습니다.
(이 폴더는 `docs/` 아래라 배포되지 않습니다. 사용자가 보낸 참고 그림 원본은 저작권 때문에 올리지 않고 글로만 적었습니다.)
