# 디자인 회의록 — 패미컴 시안 작업 (2026-10-26 ~ 10-27)

김지수(사용자)와 Claude(누렁이)가 포트폴리오 첫 화면 · 사이트 디자인을 두고 나눈 이야기와 결정, 그에 따른 시안을 시간 순으로 정리했습니다.
시안은 모두 저장소에 있고 갤러리(`themes.html`)나 `index.html?skin=<시안 id>` 로 열어 볼 수 있습니다.
Codex(보조 에이전트)에게 준 지시서는 [`briefs/`](briefs/), 회차별 비교 화면은 [`images/`](images/) 에 있습니다.
(이 폴더는 `docs/` 아래라 배포되지 않습니다. 사용자가 보낸 참고 그림 원본은 저작권 때문에 올리지 않고 글로만 적었습니다.)

## 회의 기록

### 10-26 · 준비
- **사용자**: 현재 진행 상황 보고 → Codex CLI 를 보조 에이전트로 연결(ChatGPT 계정 로그인, read-only 테스트).
- **결과**: 연결 완료, 이후 시안 작업의 '두 번째 손'으로 Codex 사용.

### 10-26 · 1회차 — 전체 레이아웃 · 디자인 퀄리티업
- **사용자**: "코덱스로 사이트 전체 레이아웃과 디자인 퀄리티업 시도해 보고 시안 몇 개, 서로 비슷한 거 말고 다양하게." (Codex 는 최신 sol 모델)
- **결과**: 에디토리얼 · 브랜드 벤토 · HUD 런처 · 스크랩북 · 퀘스트 로그 등 테마 단위 시안.
- **사용자**: "빨/검/흰 닌텐도 콘셉트는 그대로 두고 그 안에서 레이아웃 · 디자인을 만지라는 것." → "더 퇴보하고 있잖아."
- **질문과 답(Claude → 사용자)**: 어디까지 손대도 되나? → "패미컴 화면 콘셉트와 칩 넣기는 유지, 색 · 테마 콘셉트(빨강 패미컴 위주)는 반드시 유지. 첫 화면에서 프로젝트 하나 보는 뎁스가 많은 게 아쉽다."
- **사용자**: "뭐 레이아웃이나 디자인이 달라진 게 하나도 없잖아." → "바리에이션 주지 말고 **다르게** 만들라고."

### 10-27 · 2회차 — 디자인 언어 자체를 다르게
- **결과**: 제품 사진(`fc-3d`) · 도트 아트(`fc-8bit`) · 박스아트(`fc-boxart`). 카트리지 1클릭 꽂기 → 바로 상세(뎁스 줄임).
- **사용자**: "1번처럼 패미컴 기울여 놓은 것도 나쁘지 않은데, **패미컴에 넣는 프로젝트 카드들도 같은 구도로 패미컴 밑에**." → 진열판을 게임기 바로 밑 같은 기울기로.
- **사용자**: "화풍이 별로네, 화풍 좀 바꿔 봐." → 같은 구도에 그림체만 바꾼 클레이 · 만화 · 80년대 광고(`fc-clay` · `fc-toon` · `fc-airbrush`).
- **사용자**: "픽셀 화풍도 하나. 이번에만 Codex 가 만든 고품질 화풍을 네가 픽셀로 변환하는 식으로." → `fc-pixel`(렌더 → 픽셀 변환 도구 `tools/fc-pixel/`).

### 10-27 · 3회차 — 원래 패미컴 디자인으로 돌아가기
- **사용자**: "닌텐도 디자인은 원래 쓰던 게 훨씬 낫다(퀄리티는 낮지만). 그대로 쓰든 3D 픽셀 · 복셀로 만들든 다시 몇 개. **화려 · 감성보다 게임답게**."
- **결과**: 정돈(`fc-classic`) · 3D 픽셀(`fc-px3d`) · 복셀(`fc-voxel`), 공용 구도 스크립트 `fc-stage.js`.
- **사용자**: "평면 말고 **아까 그 구도로**." → 세 안을 기울인 구도로.
- **사용자**: "픽셀 버전은 너무 구리다"(→ 진짜 도트 그림으로 다시), "픽셀 아닌데도 **계단 현상**." → 3D 픽셀을 규칙대로 찍은 스프라이트로(`tools/fc-pixel/sprites.py`), 기울인 판에 합성 레이어 · 투명 외곽선으로 계단 현상 제거.

### 10-27 · 4회차 — 참고 그림 다섯 장의 화풍
- **사용자**(그림 5장: 노을빛 픽셀 아이콘 · 흰 바탕 아이소 도트 · 지시선 분해도 · 하늘색 플랫 일러스트 · 일본 레트로 판화): "구도도 달라지고 퀄리티도 떨어졌다. **구도는 살짝 3D 로 돌아간 형태로 고정**, 그림들을 하나하나 녹여 각각 시안으로. **색과 화풍 위주**, 패미컴 실루엣은 그대로."
- **결과**: ① 픽셀 아이콘 · ② 도트 · ③ 분해도 · ④ 플랫 · ⑤ 레트로 판화 (Codex 5개 병렬, [지시서](briefs/r2-reference/)).

### 10-27 · 5회차 — 재해석 + 새 참고 그림 다섯 장
- **사용자**: "5개 다 독특하지만 그대로 쓰긴 어렵다. 재해석해서 더 바꿔 봐." + 새 그림 5장(아이소 만화풍 게임기 · 슈퍼 패미컴 미니 상자 선화 · 호박색 고해상 도트 · 패미컴 40주년 포스터 · 8비트 스테이지): "얘네로도 각각 시안."
- **Claude 진단**: 화풍이 첫 화면에만 머묾 · 소품을 스티커처럼 옮김 · 강한 색 위 작은 글자.
- **결과**: ①~⑤ 재해석 + ⑥ 아이소 · ⑦ 컬러 선화 · ⑧ 고해상 도트 · ⑨ 크라프트 · ⑩ 스테이지 ([지시서](briefs/r3-reinterpret/), [화면](images/r3-a-reinterpret.jpg) · [화면](images/r3-b-new5.jpg)).

### 10-27 · 6회차 — 색이 아니라 그리는 방식부터

- **결과**: 10개 안 다시 그림 ([지시서](briefs/r4-redraw/), [흑백 시험](images/r4-grayscale-test.jpg), [화면](images/r4-a-redraw.jpg) · [화면](images/r4-b-redraw.jpg)).

### 10-27 · 7회차 — ② 도트 · ⑨ 크라프트 · ⑩ 스테이지 다듬기
- **사용자**: "2, 9, 10이 콘셉트는 괜찮은데 퀄리티가 좀 낮다." → (Claude 가 직접 수정) 도트 카드가 정사각으로 눌린 버그, 뭉개진 제목, 크라프트 긁힌 질감 · 흐린 액정, 스테이지 흐릿한 도트 본문 · 무거운 머리 ([전후](images/r5-dot-kraft-level-polish.jpg)).
- **사용자**: "뭔가 살짝 아쉬운데 한 번만 다시." → 비어 있던 첫 화면 왼쪽에 각 그림의 소품(도트 패드 · 블록과 코인) ([화면](images/r6-left-side-props.jpg)).
- **사용자**: "뭔가 저 게임기 — 그림 자체가 아쉽다, 깨져 있는 느낌, 조잡, 뚱하다, 크기 · 기울기 · 자리." + "모서리 외곽선 끊겨 있는 거 없어야 함."
  → 게임기 몸통을 상자 조각 대신 **SVG 그림 한 장**(`fc-body.js`)으로, 도트는 칸 격자에 칠하고 외곽선을 실루엣에서 계산, 비율을 날씬하게 · 기울기 조금 줄임 ([확대](images/r7-svg-consoles-2x.jpg)).
- **사용자**: "훨씬 나아졌는데 끝부분에 픽셀 하나 더 들어감." → 모서리를 한 칸씩 물러나는 45° 계단으로 ([모서리](images/r7-pixel-corners.jpg)).
- **사용자**: "(크라프트) 너무 평면적이라 잘 안 보임, 그림자나 입체감." → 두께 · 그늘 · 바닥 그림자 · 볼록 버튼 ([화면](images/r7-kraft-depth.jpg)).
- **사용자**: "훨 낫긴 하네."

### 10-27 · 10회차 — 네 안 골라 포트폴리오답게 다듬기
- **사용자**(후보 9개 비교 화면에서): "도트 · 크라프트 · 스테이지 · 랠리 프린트가 괜찮은데, 이거 기준으로 좀 더 **포트폴리오 사이트답게** 깎아 볼래? 지금은 뭔가 **조잡해**."
- **Claude 진단**(네 안 공통): 첫 화면 왼쪽을 스티커 같은 소품으로 메움 · 안내 문구 11px · 첫 화면과 아래 절의 왼쪽 선이 서로 다름(x 93 ↔ 133~193) ·
  본문 12~14px · 상자 안의 상자와 겹겹 두께 면 · 절 끝에 떠 있는 '더 보기' 버튼 · 안마다 과한 장식(크라프트의 첫 화면을 감는 굵은 선로, 스테이지의 벽돌 기둥 · 계단 카드 · 구름, 도트의 메뉴까지 도트 글꼴).
- **결과**: 공용 다듬기 파일 `assets/css/themes/pixel-fc-folio.css`(시안 CSS 뒤에 읽힘) + 안별 조정.
  - 첫 화면 왼쪽: 소품 대신 **이력서 숫자 줄**(300K+ · 7종 · 60K+ · 10년, `resume.stats` 에서) · 제목 키움 · 안내 15px.
  - 첫 화면 · 모든 절 · 푸터를 같은 폭(1240px) · 같은 왼쪽 선으로. '더 보기'는 오른쪽 글자 링크.
  - 도트: 큰 테두리 절 상자 → 번호 배지 + 굵은 선 머리, 강점 · 게임플레이는 세 장 카드, 두께 면은 큰 면에만, 메뉴는 읽히는 글꼴.
  - 크라프트: 선로는 첫 절부터 내려가는 가는 선 하나, 스티커(컨트롤러 · 별 · 하트 · 코인) 제거.
  - 스테이지: 카드 = 벽돌 턱 한 줄 + 남색 테 발판, 강점 카드 같은 높이(기둥 제거), 절 사이 구름 제거, 큰 글자 외곽선 → 그림자 하나, 하늘 위 숫자는 밝은 글자.
  - 랠리 프린트: 사선 엠블럼 · 절 사이 전폭 구분선 제거, 보유 기술 아이콘을 다섯 칸에 고르게.
  - 6개 페이지 × 라이트/다크 × 1440/390px 확인 · 덱 뽑기 → 카트리지 꽂기 → 개요 → 언어 전환 동작 확인(오류 0).
