# 디자인 회의록 — 패미컴 시안 작업 (2026-10-26 ~ 10-28)

김지수(사용자)와 Claude(누렁이)가 포트폴리오 첫 화면 · 사이트 디자인을 두고 나눈 이야기와 결정, 그에 따른 시안을 시간 순으로 정리했습니다.
시안은 모두 저장소에 있고 갤러리(`themes.html`)나 `index.html?skin=<시안 id>` 로 열어 볼 수 있습니다.
Codex(보조 에이전트)에게 준 지시서는 [`briefs/`](briefs/), 회차별 비교 화면은 [`images/`](images/) 에 있습니다.
(이 폴더는 `docs/` 아래라 배포되지 않습니다. 사용자가 보낸 참고 그림 원본은 저작권 때문에 올리지 않고 글로만 적었습니다.)

### 10-28 · 11회차 — 첫 화면 아래까지 '게임 화면'으로 (Claude 판 네 안)
- **사용자**: "음 왤케 아쉽지" → "아니 **내용이 아니라 실제 스킨**이 아쉬움."
- **Claude 진단**: 게임 같은 건 게임기 테두리까지뿐. 게임기 화면 안은 웹 양식(이름 · 입력칸 같은 한마디 · 버튼 두 개)이고, 그 아래 절은 어느 사이트에나 있는 카드 묶음이라
  게임이라는 설정이 베젤에서 끊김. 랠리는 한글에 없는 기울임꼴을 브라우저가 억지로 눕힌 가짜 이탤릭, 진열판은 작은 카트리지 넷이 빽빽해 시끄러움.
- **제안**: 게임기 화면 = 플레이어 선택 화면 · 절 = 이름표 달린 RPG 대화창 · 창 안 목록 = 퀘스트 / 인벤토리 / 업적 / 저장 슬롯 · 가짜 이탤릭 제거 · 카트리지는 크게.
  빨강 · 검정 · 흰색 패미컴 콘셉트 · 카트리지 꽂기 · 기울인 구도는 그대로.
- **사용자**: "각각 시안 테마마다 다시 시도해봐."
- **결과**: `pixel-fc-folio.css` 에 '게임 UI' 공용 절을 더하고 안마다 `--gui-*` 토큰으로 창을 그리는 방식만 다르게. `fc-stage.js` 가 화면 맨 위에 '1P · 플레이어 선택' 띠를 붙임.
  - 게임기 화면: 1P 띠 · 대화창 한마디(끝에 ▼) · 버튼 두 개 → **▶ 커서 세로 메뉴**(첫 줄 기본 선택, 마우스 · 초점을 따라 이동, 모션 최소화면 깜빡임 끔).
  - 홈: 대외 활동(퀘스트 목록) + 보유 기술(인벤토리 세 칸, 줄이 덜 차면 빈 칸) 창을 메뉴 화면처럼 나란히, 강점 = 업적 세 칸, 게임플레이 = 번호 붙은 저장 슬롯.
    각 항목은 자기 상자 · 그림자 · 두께 면을 벗고 창 하나에 담김.
  - 하위 페이지: 이력서 숫자 = 상태 창, 인적사항 · 핵심역량 · 경력(진행 중인 줄에 ▶) · 자기소개서 본문(대화창 + ▼) · 게임플레이 그래프 · 상세의 배운 점 · 이전/다음이 모두 창. 절 제목은 독립 이름표, 같은 말을 되풀이하던 눈썹 칩은 접음. 프로젝트 분류 탭은 고른 칸에 ▶.
  - 진열판: 덱 + 3장(980px 이상) — 카트리지 한 장이 1.25배 커지고 판이 조용해짐. 카드 안쪽 칸은 그대로.
  - 안별 창: **도트** 검은 4px 테 + 크림 겹띠 + 회색 그림자, 검은 이름표에 빨간 번호 칸 · **크라프트** 진홍 겹선의 둥근 종이 창, 끈 구멍 뚫린 꼬리표(케이블이 꼬리표를 이음) ·
    **스테이지** 하늘 위 남색 대화창 + 크림 테 + 파란 안선, 물음표 블록 달린 크림 이름표 · **랠리** 검은 3px 테 + 노랑 판화 그림자, 사선으로 자른 빨강 이름표(글자는 곧게).
  - 랠리의 기울임꼴(로고 · 눈썹 · 큰 제목 · 버튼 · 카드 이름 · 절 제목 · 숫자 · 표 머리)과 글자까지 눕히던 skew 를 모두 곧은 글자로 — 사선은 상자 모양(clip-path)만.
  - 함께 고친 것: 스테이지 절이 첫 화면보다 바깥(데스크톱 x 53)·화면 끝(모바일 x 0)에 붙던 정렬, 하늘 위 작은 글자 대비(남색으로), 다크에서 이름이 안 보이던 게임기 화면 글자,
    도트 다크의 게임플레이 그래프 · 표 글자.
  - 6개 페이지 × 라이트/다크 × 1440/390px(오류 · 가로 넘침 0) · 덱 뽑기 → 카트리지 꽂기 → 개요 → 언어 전환(EN 띠 'PLAYER SELECT') · 사진 무변형 · 로고 판 흰색 · 기울임꼴 0 확인.
