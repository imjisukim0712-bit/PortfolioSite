# 스팀 플레이 기록 연동 — 켜는 법 · 빼는 법

게임플레이 페이지(`play.html`) 맨 위에 **장르별 플레이 시간 방사형 그래프**를 띄웁니다.
스팀에서 기록을 모으는 일은 깃허브가 대신 하고(주 1회), 화면은 그 결과 파일만 읽습니다.

| 무엇 | 어디 |
|---|---|
| 모으는 스크립트 | `tools/steam-sync.mjs` |
| 자동 실행 | `.github/workflows/steam-sync.yml` (월요일 03:00 KST · 수동 실행 가능) |
| 결과 (화면이 읽는 파일) | `assets/play-steam.js` — 자동으로 쓰입니다. 직접 고치지 마세요 |
| 설정 (내가 고치는 곳) | `assets/content.js` 의 `play.steam` |
| 그리는 코드 | `assets/js/render.js` 의 `steamBlock()` · 스타일은 `style.css` 의 `.steam` |

> 연동 전에는 `assets/play-steam.js` 가 비어 있고, **그래프 자리는 아예 나오지 않습니다.**
> 지금 페이지는 예전 그대로이니 준비되면 아래 3단계만 하면 됩니다.

---

## 1. 켜기 — 3단계 (10분)

**① 스팀 API 키 발급** — <https://steamcommunity.com/dev/apikey>
도메인 칸에는 아무 값(예: `localhost`)이나 넣어도 됩니다. 계정이 '제한 계정'이 아니어야 합니다(스팀에서 $5 이상 결제 이력 필요).

**② 내 SteamID64 확인** — 17자리 숫자입니다.
스팀 프로필 주소가 `.../profiles/7656119...` 면 그 숫자가 바로 그것이고,
`.../id/닉네임` 형태면 <https://steamid.io> 같은 곳에서 변환하면 됩니다.
같이, **프로필 → 개인정보 설정에서 '프로필'과 '게임 상세 정보'를 공개**로 바꿔 주세요.
비공개면 스팀이 목록을 주지 않아 그래프가 비어 있게 됩니다.

**③ 깃허브에 등록** — 저장소 **Settings → Secrets and variables → Actions → New repository secret**
| 이름 | 값 |
|---|---|
| `STEAM_API_KEY` | ①에서 받은 키 |
| `STEAM_ID` | ②의 17자리 숫자 |

그다음 **Actions 탭 → "Steam play log" → Run workflow** 를 한 번 눌러 주세요.
첫 실행은 게임 수만큼 상점 정보를 받느라 몇 분 걸립니다(스팀이 5분에 200회로 제한해 천천히 받습니다).
끝나면 결과가 자동으로 커밋되고 사이트도 다시 배포됩니다.

키는 깃허브 Secrets 에만 있고 사이트·저장소에는 절대 들어가지 않습니다.

---

## 2. 빼기 — 자동 + 직접

### 자동으로 빠지는 것 (아무것도 안 해도 됨)

- 스팀 **콘텐츠 표시 1·3·4** (노출·성적 콘텐츠)가 붙은 게임
- **장르 71(성적 콘텐츠)·72(노출)** 게임
- **연령 제한 18세 이상**, 또는 상점이 정보를 안 주는 연령 게이트 게임
- **게임이 아닌 소프트웨어** (월페이퍼 엔진 같은 것 — `skipSoftware: true`)
- **60분 미만** 논 게임 (`minMinutes`)

빠진 게임은 **집계 전에** 걸러지므로 공개되는 `assets/play-steam.js` 에 이름조차 들어가지 않습니다.
(실행 기록에도 성인 게임 이름은 찍지 않습니다.)

### 직접 빼기

`assets/content.js` → `play.steam.exclude` 에 **appid 숫자**나 **이름 일부**를 적으면 됩니다.

```js
exclude: [ 431960, "Wallpaper", 1234567 ],
```

- 숫자 = 스팀 appid (상점 주소 `store.steampowered.com/app/431960/...` 의 그 숫자)
- 문자열 = 게임 이름에 그 말이 들어가면 제외 (대소문자 구분 없음)
- appid 는 Actions 실행 기록에 **집계에 들어간 게임 목록(appid · 시간 · 이름)** 으로 찍히니 거기서 골라 복사하면 됩니다.

고친 뒤에는 워크플로를 한 번 더 돌리면(Run workflow) 바로 반영됩니다.

## 3. 손볼 만한 설정 (`assets/content.js` → `play.steam`)

| 키 | 기본값 | 뜻 |
|---|---|---|
| `minMinutes` | `60` | 이만큼(분) 못 논 게임은 빼기 |
| `axes` | `6` | 방사형 축 개수 (5~7 권장, 나머지는 '그 외 장르'로 묶임) |
| `topCount` | `8` | 결과 파일에 이름을 남길 게임 수 — 줄이면 공개되는 게임 이름이 줄어듭니다 |
| `fetchLimit` | `140` | 한 번 실행에 새로 받을 상점 정보 수 (호출 제한 대비) |
| `skipSoftware` | `true` | 게임 아닌 소프트웨어 빼기 |
| `exclude` | `[]` | 직접 빼는 목록 (위 참고) |
| `excludeGenres` | `[23, 37, 70]` | 축으로 세우지 않을 장르 — 인디·무료 플레이·앞서 해보기 (판매 형태에 가까움) |
| `genreNames` | 11종 | 장르 id → 우리말·영어 이름. 없는 id 는 스팀이 준 영어 이름을 그대로 씁니다 |

글자(제목·라벨)도 모두 `play.steam` 안에 `{ ko, en }` 으로 있습니다 — 한국어를 고치면 영어도 함께 고쳐 주세요.

## 4. 화면 구성

- **방사형 그래프** — 장르별 **플레이 시간**. 계열이 하나뿐이라 색은 강조색 하나만 쓰고 범례를 두지 않습니다.
  눈금은 **제곱근**이라 한 장르가 압도적이어도 나머지 모양이 뭉개지지 않고, 실제 숫자는 축마다 적혀 있습니다.
- **요약** — 총 플레이 시간 · 집계 게임 수 · 요즘 하는 게임
- **표** — 그래프와 같은 내용(장르 / 시간 / 게임 수). 그래프를 못 읽는 경우(스크린 리더·색약·인쇄)를 위한 자리이자,
  정확한 숫자를 보는 자리입니다. '그 외 장르' 줄에 축에 못 들어간 나머지가 합쳐집니다.
- 그 아래 **직접 쓴 게임 카드**(`play.cards`)는 그대로입니다 — 자동 수치가 위, 직접 쓴 해설이 아래.

## 5. 알아 둘 점

- **스팀 밖 기록은 안 잡힙니다** — 모바일·콘솔·스팀 미등록 게임은 아래 카드로 직접 써 주세요.
  그래서 그래프 설명에 '스팀 라이브러리 기준'이라고 적어 두었습니다.
- **플레이 시간은 누적만 옵니다** — 스팀이 연도별 추이를 주지 않습니다.
- **한 게임이 여러 장르면** 시간을 장르 수로 나눠 담습니다 (합계가 총 시간과 맞도록).
  예: 스텔라리스 600시간, 장르가 전략·시뮬레이션 → 각각 300시간.
- **호출 제한** — 상점 정보(장르)는 비공식 API 라 5분에 200회쯤이 한계입니다. 받은 값은
  `tools/steam-cache.json` 에 쌓아 두고 다음 실행부터는 새 게임만 받습니다. 게임이 아주 많으면
  첫 실행에서 다 못 받을 수 있는데, 다음 실행에서 이어서 받습니다.
- **결과가 비어 보일 때** — ① 프로필의 '게임 상세 정보'가 공개인지 ② Secrets 두 개가 맞는지
  ③ Actions 실행 기록의 마지막 줄(장르 축 목록)을 확인해 보세요.
