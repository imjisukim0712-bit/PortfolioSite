# 김지수 · 게임 기획자 포트폴리오

🔗 **사이트 바로가기 → https://imjisukim0712-bit.github.io/PortfolioSite/**

빌드 도구 없는 정적 사이트입니다. **내용과 화면이 분리돼 있어, 글을 고칠 때 HTML을 건드릴 필요가 없습니다.**

- 폰트: **Pretendard Variable** (jsDelivr CDN)
- 디자인: 첨부 **Phantom** 스타일 (라벤더 · 오베르진, 100px 알약, weight 350) + **다크모드**
- 반응형: 모바일 우선, 320px까지 가로 스크롤 없음
- iOS / Safari: `viewport-fit=cover` + `env(safe-area-inset-*)`, `100svh`, `-webkit-backdrop-filter`, `scroll-behavior` 폴백

## 페이지 구조 (별도 페이지)

```
index.html          홈 — 히어로 + 고스트 + 이력서/포트폴리오 + 프로젝트 카드 뽑기
resume.html         이력서 — 히어로 → 숫자요약 · 핵심역량 · 경력
cover-letter.html   자기소개서 — (지금은 비어 있음, 편집기에서 채움)
projects.html       프로젝트 — 게임/기획 탭 + 카드 그리드
projects/detail.html?p=<id>   프로젝트 상세 — 좌측 정보 + 우측 미디어 (자동 생성)
play.html           게임플레이 — 플레이한 게임 기록
edit.html           내용 편집기 (비밀번호 잠금)
```

헤더 목차: **홈 · 이력서 · 자기소개서 · 프로젝트 · 게임플레이** + 언어(KR/EN) + 다크모드 + 이력서

### 특징적인 동작
- **접이식 헤더**: 데스크톱에서 평소 접혀 있다가 헤더에 커서를 올리거나 아래 ⌄ 손잡이를 누르면 펼쳐집니다. 모바일은 햄버거 메뉴.
- **다크모드**: 헤더의 달/해 아이콘으로 전환. 처음엔 기기 설정을 따르고, 한 번 고르면 그 선택을 기억합니다.
- **카드 뽑기**: 홈 하단 카드 스택을 누르면 프로젝트가 랜덤으로 펼쳐지고, 카드를 누르면 해당 프로젝트로 이동합니다. (프로젝트가 4개보다 적으면 있는 만큼)
- **게임/기획 탭**: 프로젝트 페이지에서 분류별로 필터링.

## 내용 고치기

### 방법 A — 편집기 (권장)
`edit.html` 을 열면 (비밀번호 `0000`) 폼으로 모든 내용을 고칠 수 있습니다.
- `한` / `EN` 나란히 입력, EN 비우면 영어 화면에서도 한국어가 그대로 나옵니다
- `+ 추가` / `↑ ↓` / `✕` 로 항목 추가·순서변경·삭제
- **미리보기**로 확인 → **저장하고 반영**(설정에 GitHub 토큰 등록 시) 또는 **content.js 내보내기**

### 방법 B — 파일 직접 수정
`assets/content.js` 하나만 고치면 됩니다. `{ ko: "...", en: "..." }` 형태.

### 프로젝트 추가
`projects.items` 에 항목을 넣으면 **상세 페이지가 자동 생성**되고, 홈 카드 뽑기 풀에도 들어갑니다.
`category` 를 `"game"` 또는 `"planning"` 으로 지정하면 프로젝트 탭에서 필터됩니다.
상세 미디어는 `media.embed` 에 유튜브/영상/웹게임 임베드 URL 을 넣으면 그대로 삽입됩니다 (비우면 안내 문구).

## 디자인 테마 시안 (테마 4종 · 시안 7개)
`themes.html` 에서 전체 시안을 보고, 카드를 누르면 그 디자인이 입혀진 실제 사이트가 열립니다.

| 테마 | 시안 id |
|---|---|
| 레트로 픽셀 아케이드 | `pixel-famicom` |
| 네오 브루탈리즘 | `brutal-cyberpunk` · `brutal-newsprint` |
| 브랜드 홈페이지 | `brand-keynote` |
| 컨셉 무대 | `concept-spec` · `concept-patch` · `concept-tabletop` |

- **공통 요소**: 모든 시안의 홈 히어로 뒤에 본문 폭의 색면(판)이 깔리고, 사진 옆에 말풍선 '한마디'와 **한 마디 더** 버튼이 있습니다 (`content.js` 의 `home.quips`). 버튼을 누를 때마다 문장이 바뀌고 사진 카드가 살짝 움직입니다. '함께 일하면, 이런 기획자입니다.' 강점 세 장은 홈의 덱 바로 아래와 자기소개서 맨 위에 카드로 붙습니다 (`coverLetter.summary`).
- **패미컴 시안**: 홈·이력서 첫 화면이 휴대용 게임기 한 대입니다. 왼쪽 손잡이의 **SELECT ◀ ▶** 로 사진 옆 한마디를 넘기고(이력서 페이지에서는 이전·다음 절로 이동), **B** 는 다크·라이트 전환, **A** 는 홈에서 프로젝트 뽑기(그 밖에서는 아래로). 프로젝트 카드와 뽑기 덱은 카트리지 모양이고, 카드를 누르면 카트리지가 게임기 슬롯에 꽂히는 연출 뒤에 화면에 프로젝트 개요가 뜨고, **자세히 보기**(A)로 그 페이지에 들어가거나 **꺼내기**(B)로 되돌립니다. 이 부분은 `assets/js/themes/famicom.js` 가 맡습니다.
- **둘러보기**: 아무 페이지 주소에 `?skin=<시안 id>` 를 붙이면 그 뒤로 모든 페이지에 유지되고, 왼쪽 아래 **테마 시안** 버튼으로 바꿔 볼 수 있습니다. `?skin=default` 로 되돌립니다.
- **지금 적용된 디자인**: `pixel-famicom` (레트로 픽셀 아케이드 · 패미컴). `assets/js/themes.js` 맨 위 `DEFAULT_SKIN` 한 줄로 정해집니다 — 다른 시안 id 로 바꾸거나, 빈 문자열로 두면 기본 디자인으로 돌아갑니다.
- **구조**: 시안 하나 = `assets/css/themes/<테마>.css`(테마 공통) + `<테마>-<시안>.css`(색·글꼴·무늬). 기본 `style.css` 위에 덧입히는 방식이라 내용·동작은 그대로이고, 색은 시안 파일의 토큰만 바꾸면 됩니다. 글꼴은 Google Fonts(픽셀 테마는 jsDelivr 의 Galmuri)에서 불러옵니다. 사진에는 어떤 필터·보정도 걸지 않습니다.
- 갤러리 미리보기 이미지는 `assets/img/themes/<시안 id>.jpg` 입니다.
