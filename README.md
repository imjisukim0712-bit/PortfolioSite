# 김지수 · 게임 기획자 포트폴리오

🔗 **사이트 바로가기 → https://imjisukim0712-bit.github.io/PortfolioSite/**

빌드 도구 없는 정적 사이트입니다. **내용과 화면이 분리돼 있어, 글을 고칠 때 HTML을 건드릴 필요가 없습니다.**

- 폰트: **Pretendard Variable** (jsDelivr CDN)
- 디자인: 첨부 **Phantom** 스타일 (라벤더 · 오베르진, 100px 알약, weight 350) + **다크모드**
- 반응형: 모바일 우선, 320px까지 가로 스크롤 없음
- iOS / Safari: `viewport-fit=cover` + `env(safe-area-inset-*)`, `100svh`, `-webkit-backdrop-filter`, `scroll-behavior` 폴백

## 페이지 구조 (별도 페이지)

```
index.html          홈 — 히어로 + 고스트 + 이력서/포트폴리오 + 프로젝트 카드 뽑기
resume.html         이력서 — 히어로 → 숫자요약 · 핵심역량 · 경력
cover-letter.html   자기소개서 — (지금은 비어 있음, 편집기에서 채움)
projects.html       프로젝트 — 게임/기획 탭 + 카드 그리드
projects/detail.html?p=<id>   프로젝트 상세 — 좌측 정보 + 우측 미디어 (자동 생성)
play.html           게임플레이 — 플레이한 게임 기록
edit.html           내용 편집기 (비밀번호 잠금)
```

헤더 목차: **홈 · 이력서 · 자기소개서 · 프로젝트 · 게임플레이** + 언어(KR/EN) + 다크모드 + 이력서

### 특징적인 동작
- **접이식 헤더**: 데스크톱에서 평소 접혀 있다가 헤더에 커서를 올리거나 아래 ⌄ 손잡이를 누르면 펼쳐집니다. 모바일은 햄버거 메뉴.
- **다크모드**: 헤더의 달/해 아이콘으로 전환. 처음엔 기기 설정을 따르고, 한 번 고르면 그 선택을 기억합니다.
- **카드 뽑기**: 홈 하단 카드 스택을 누르면 프로젝트가 랜덤으로 펼쳐지고, 카드를 누르면 해당 프로젝트로 이동합니다. (프로젝트가 4개보다 적으면 있는 만큼)
- **게임/기획 탭**: 프로젝트 페이지에서 분류별로 필터링.

## 내용 고치기

### 방법 A — 편집기 (권장)
`edit.html` 을 열면 (비밀번호 `0000`) 폼으로 모든 내용을 고칠 수 있습니다.
- `한` / `EN` 나란히 입력, EN 비우면 영어 화면에서도 한국어가 그대로 나옵니다
- `+ 추가` / `↑ ↓` / `✕` 로 항목 추가·순서변경·삭제
- **미리보기**로 확인 → **저장하고 반영**(설정에 GitHub 토큰 등록 시) 또는 **content.js 내보내기**

### 방법 B — 파일 직접 수정
`assets/content.js` 하나만 고치면 됩니다. `{ ko: "...", en: "..." }` 형태.

### 프로젝트 추가
`projects.items` 에 항목을 넣으면 **상세 페이지가 자동 생성**되고, 홈 카드 뽑기 풀에도 들어갑니다.
`category` 를 `"game"` 또는 `"planning"` 으로 지정하면 프로젝트 탭에서 필터됩니다.
상세 미디어는 `media.embed` 에 유튜브/영상/웹게임 임베드 URL 을 넣으면 그대로 삽입됩니다 (비우면 안내 문구).

## 로컬 실행 / 배포
```bash
python3 -m http.server 8000   # http://localhost:8000
```
`.github/workflows/deploy-pages.yml` 이 브랜치 푸시마다 자동 배포합니다.
저장소 Settings → Pages → Source 가 **GitHub Actions** 여야 합니다.
