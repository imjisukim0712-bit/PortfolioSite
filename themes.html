Click a card to open the real site wearing that design; it sticks across pages. Use the Theme button at the bottom-left of the site to switch anytime.

확정하려면 assets/js/themes.js 맨 위 DEFAULT_SKIN 에 시안 id(예: pixel-famicom)를 적어 두면 방문자 모두에게 그 디자인이 보입니다. 각 시안은 assets/css/themes/ 의 CSS 파일 두 개(테마 공통 + 시안)로 되어 있어 색·글꼴을 자유롭게 고칠 수 있습니다. To make one permanent, set DEFAULT_SKIN at the top of assets/js/themes.js to a draft id (e.g. pixel-famicom). Each draft is two CSS files in assets/css/themes/ (theme base + draft), so colours and fonts are easy to tweak.
